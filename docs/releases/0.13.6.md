# Freedraw PDF 0.13.6 — iPad fork

Fork of vividasasana/freedraw-pdf by vida sana, preserving the MIT license.

- Preserve native finger touchstart for pinch zoom and hand off finger capture when a second finger arrives.
- Restore overlay input and page synchronization after all pinch contacts end or cancel.
- Pause annotation rendering during pinch navigation.
- Reduce stroke geometry processing by keeping captured sample density during smoothing.
- Add a solid ballpoint preset with low pressure width variation and rounded caps.

Production build and the full local automated suite passed, including pan/pinch/lift/Pencil input replay. A local geometry benchmark measured approximately threefold faster processing. Physical iPad responsiveness and pen appearance remain to be verified on device.

Install using BRAT with `dhairyapatel915/freedraw-pdf-ipad`, then select Use ballpoint in plugin settings. The plugin ID is unchanged, so this replaces an existing Freedraw PDF installation. Back up existing plugin settings and annotation sidecars before installing.
